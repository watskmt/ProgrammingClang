マス目の座標

マスの列と行の番号から、そのマスの中に描く正方形の座標と、マスの中心に描く円の座標を求めます。マスをクリックするか、右のスライダーを動かして確かめられます。

原点 (0, 0) は左上 始点 (x1, y1) と終点 (x2, y2) マス目の開始位置 番号 × マスの大きさ マス内の余白 正方形 円(中心はマスの中心)

円の中心の求め方

円は「中心の座標」と「半径」で決まります。DrawBoxのように左上と右下を求める必要はなく、マスの中心の1点が分かれば描けます。下の4つの手順で求めます。設定のスライダーやマスの選択を変えると、図と計算が更新されます。

マス 正方形 円 マスの左上と円の中心

  1. 1. マスの左上を求める

    マス目は (gx, gy) から始まり、1マスの大きさは c です。右へ col マス、下へ row マス進んだ位置が、選んだマスの左上です。

  2. 2. 中心までの距離を考える

    マスは縦も横も c の正方形なので、中心は左上から右へ c ÷ 2、下へ c ÷ 2 進んだ点です。

  3. 3. 足し合わせる

    手順1の左上に、手順2の c ÷ 2 を足したものが円の中心 (cx, cy) です。これを DrawCircle の x、y に渡します。

  4. 4. 半径を決める

    半径 r は、円がマスからはみ出さないように c ÷ 2 以下にします。c ÷ 2 ちょうどなら円がマスに内接し、正方形に収めたいときは s ÷ 2 にします。

別の求め方: 正方形の中心から

正方形をマスの中央に置いているなら、正方形の中心を求めても同じ点になります。DrawBoxの左上 x1 に s ÷ 2 を足し、式を整理すると手順3の式になります。

x1 + s ÷ 2 = (gx + col × c + (c − s) ÷ 2) + s ÷ 2
           = gx + col × c + (c − s + s) ÷ 2
           = gx + col × c + c ÷ 2
           = cx

C言語での書き方

全マスの中心に円を描く例です。行と列のループの中で、手順3の式をそのまま書きます。

const int gx = 24, gy = 24;   // マス目の左上
const int c  = 64;            // マスの大きさ
const int r  = 16;            // 円の半径
const unsigned int white = GetColor(255, 255, 255);

for (int row = 0; row < 4; row++) {
    for (int col = 0; col < 6; col++) {
        int cx = gx + col * c + c / 2;
        int cy = gy + row * c + c / 2;
        DrawCircle(cx, cy, r, white, TRUE);
    }
}

DrawCircle の呼び出しを座標の表示に置き換えて実行した結果(gcc -Wall -Wextra で警告なし)。各行が1行分のマスの中心 (cx, cy) です。

( 56,120) (120,120) (184,120) (248,120) (312,120) (376,120)
( 56,184) (120,184) (184,184) (248,184) (312,184) (376,184)
( 56,248) (120,248) (184,248) (248,248) (312,248) (376,248)

cx は列が1つ進むたびに 64(= c)ずつ、cy は行が1つ進むたびに 64 ずつ増えています。

つまずきやすい点

  • c / 2 は int 同士の割り算なので、小数点以下が切り捨てられます。c が奇数で 45 のとき、45 / 2 は 22.5 ではなく 22 です。中心が 0.5 ピクセルずれるので、c は偶数にしておくと確実です。この資料のスライダーは、c を4刻みにしています。
  • DrawBoxの引数は左上と右下の2点、DrawCircleの引数は中心と半径です。円に (c − s) ÷ 2 の余白を足す必要はありません。余白を足すと、中心が左上へずれます。
  • 列と行の番号は 0 から数えます。1列目は col = 0 です。
  • 半径を c ÷ 2 より大きくすると、円が隣のマスにはみ出します。

確認問題

gx = 10、gy = 20、c = 50 のとき、列 3、行 2(どちらも0始まり)のマスの中心 (cx, cy) は?
cx = 10 + 3 × 50 + 50 ÷ 2 = 185
cy = 20 + 2 × 50 + 50 ÷ 2 = 145
答え: (185, 145)

DrawBoxには左上 (x1, y1) と右下 (x2, y2) を渡します。塗りつぶしでは右端と下端の座標は含まれないため、x2 = x1 + s、y2 = y1 + s とすると、ちょうど s × s ピクセルの正方形になります。正方形をマスの中央に置くので、マスの左上から (c − s) ÷ 2 だけ内側にずらしています。マスの左上へ合わせたいときは、この余白の項を 0 にします。DrawCircleには中心 (cx, cy) と半径 r を渡します。中心はマスの左上からマスの大きさの半分だけ進んだ位置で、正方形の中心 (x1 + s ÷ 2, y1 + s ÷ 2) とも一致します。
