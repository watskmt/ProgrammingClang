DXライブラリ用テンプレートの導入と使い方

Visual Studio 2022 で DXライブラリのプロジェクトを、新規作成するだけで使えるようにするテンプレートです。インクルードパスやライブラリパス、ランタイムの設定は済んでいます。

DxLibProject_VS2022.zip
プロジェクト テンプレート(約9KB)。展開せず、zip のまま使います。
zip をダウンロード

前提

次の2つが必要です。テンプレートには DXライブラリ本体は含まれていないため、別にダウンロードします。

  • Visual Studio 2022:インストーラーで「C++ によるデスクトップ開発」を入れておきます(Windows SDK も一緒に入ります)。
  • DXライブラリ:DXライブラリ置き場の「Windows版 VisualStudio(C++)用」(Ver3.25a)をダウンロードして解凍します。

導入手順(初回のみ)

  1. DXライブラリを C:\DxLib_VC に置く

    解凍したフォルダーの名前を DxLib_VC にして、C:\ の直下に置きます。次のフォルダーが存在すれば正解です。

    C:\DxLib_VC\プロジェクトに追加すべきファイル_VC用

    別の場所に置きたいとき:テンプレートは上のパスを前提にしています。置き場所を変えた場合は、あとの「つまずいたとき」を見てください。

  2. テンプレートの zip を所定のフォルダーに置く

    zip は展開せずに、そのまま次のフォルダーへコピーします。

    %USERPROFILE%\Documents\Visual Studio 2022\Templates\ProjectTemplates

    フォルダーが見つからないとき:Documents が OneDrive に移っていると、場所が違うことがあります。Visual Studio の ツール → オプション → プロジェクトおよびソリューション → 場所 にある「ユーザー プロジェクト テンプレートの場所」で、実際のフォルダーを確認できます。

  3. Visual Studio を再起動する

    起動中だった場合は、いったん終了して開き直します。

  4. 表示されないときだけ、キャッシュを更新する

    スタートメニューから「Developer Command Prompt for VS 2022」を管理者として実行し、次のコマンドを入力します。

    devenv /installvstemplates

    終わったら Visual Studio をもう一度起動します。

使い方

  1. 新しいプロジェクトを作る

    起動画面の 新しいプロジェクトの作成 を選び、検索ボックスに「DXライブラリ」と入力します。「DXライブラリ プロジェクト」を選んで「次へ」を押します。

  2. 名前と場所を決める

    プロジェクト名と保存場所を入力して「作成」を押します。プロジェクト名は、実行したときのウィンドウのタイトルにも使われます。

  3. 構成とプラットフォームを選ぶ

    ツールバーで構成を Debug、プラットフォームを x64 にします(x86 でも動きます)。

  4. 実行して確かめる

    F5 キーで実行します。1280×720 のウィンドウの中央に青い四角が出て、左上に「ESCで終了」と表示されれば成功です。ESC キーで閉じます。

  5. main.cpp に書き足す

    自動で開く main.cpp の、「初期化処理」「更新処理」「描画処理」の枠に処理を書いていきます。

最初から入っているコード(main.cpp)

ゲームでよく使う流れ(初期化、毎フレームの更新と描画、終了処理)が、すでに書かれています。

#include "DxLib.h"

namespace
{
    constexpr int kScreenWidth  = 1280;
    constexpr int kScreenHeight = 720;
    constexpr int kColorBit     = 32;
}

int WINAPI WinMain(_In_ HINSTANCE, _In_opt_ HINSTANCE, _In_ LPSTR, _In_ int)
{
    // ログファイル(Log.txt)を出力しない
    SetOutApplicationLogValidFlag(FALSE);

    // ウィンドウモード / 画面サイズ / タイトル
    ChangeWindowMode(TRUE);
    SetGraphMode(kScreenWidth, kScreenHeight, kColorBit);
    SetMainWindowText("プロジェクト名");

    // 非アクティブ時も処理を続ける
    SetAlwaysRunFlag(TRUE);

    if (DxLib_Init() == -1)
    {
        return -1;
    }

    // 描画先を裏画面に設定(ダブルバッファ)
    SetDrawScreen(DX_SCREEN_BACK);

    // ===== 初期化処理 =====


    // ===== メインループ =====
    while (ProcessMessage() == 0 && CheckHitKey(KEY_INPUT_ESCAPE) == 0)
    {
        ClearDrawScreen();

        // ----- 更新処理 -----


        // ----- 描画処理 -----
        // 画面中央に四角を描画 (左上x, 左上y, 右下x, 右下y, 色, 塗りつぶし)
        constexpr int kBoxSize = 200;
        const int left = (kScreenWidth  - kBoxSize) / 2;
        const int top  = (kScreenHeight - kBoxSize) / 2;
        DrawBox(left, top, left + kBoxSize, top + kBoxSize, GetColor(0, 160, 255), TRUE);

        DrawString(10, 10, "ESCで終了", GetColor(255, 255, 255));

        // 裏画面を表画面に反映(垂直同期待ち)
        ScreenFlip();
    }

    // ===== 終了処理 =====
    DxLib_End();

    return 0;
}

覚えておくと便利な点が3つあります。

  • SetDrawScreen(DX_SCREEN_BACK) で裏画面に描き、ScreenFlip() で表に出します(ダブルバッファ)。ちらつきを防ぐための定番の書き方です。
  • while の中の ClearDrawScreen() は、前のフレームの絵を消します。これを忘れると、前の絵が残り続けます。
  • 画面サイズは、冒頭の kScreenWidth と kScreenHeight を変えるだけで変更できます。

テンプレートの設定内容

ツールセットv143(Visual Studio 2022)
DxLib の場所C:\DxLib_VC\プロジェクトに追加すべきファイル_VC用(インクルードとライブラリの両方)
構成Debug / Release × x86 / x64
文字セットマルチバイト
ランタイムDebug は /MTd、Release は /MT(静的リンク)
C++ の規格C++20
出力先ソリューションフォルダー\bin\プラットフォーム\構成\

つまずいたとき

「DxLib.h を開けません」と出る

DXライブラリの置き場所が C:\DxLib_VC になっていません。置き直すのが簡単です。置き場所を変えたいときは、プロジェクトを右クリックして「プロジェクトのアンロード」→「プロジェクトの編集」を選び、.vcxproj の中の <DxLibDir> の行を実際のパスに書き換えます。

テンプレートが一覧に出ない

zip を展開していないか、フォルダーを間違えていないかを確認します。それでも出ないときは、導入手順の4番(devenv /installvstemplates)を試してください。

リンクエラーが出る

DXライブラリの .lib は、x86 用と x64 用が別々です。ツールバーの x86 / x64 の選択と、置いたライブラリが合っているかを確認します。ランタイムや文字セットを変えた場合も、不一致の原因になります。

Visual Studio 2026 で使いたい

このテンプレートはツールセットが v143 に固定されています。VS2026 のインストーラーで v143 ツールセット(VS2022 用の MSVC)を追加するか、プロジェクトのプロパティで新しいツールセットに変更します。環境によってはエラーが出ることがあるため、授業では VS2022 を使うのが確実です。

確認問題

問1. テンプレートの zip は、展開してから置く?そのまま置く?

展開せず、zip のまま ProjectTemplates フォルダーに置きます。展開した状態だと、Visual Studio がテンプレートとして認識しません。

問2. ゲームのループの中で、ClearDrawScreen() を書き忘れるとどうなる?

前のフレームで描いた絵が消されずに残るため、動かした物の軌跡が画面に残り続けます。

問3. ビルドで「DxLib.h を開けません」と出た。まず何を確認する?

DXライブラリのフォルダーが C:\DxLib_VC\プロジェクトに追加すべきファイル_VC用 にあるかを確認します。別の場所に置いているなら、.vcxproj の <DxLibDir> を書き換えます。

テンプレートの main.cpp は構文チェック済みです。DXライブラリ本体と Visual Studio を使った実機での動作は、この資料の作成環境では確かめていません。
