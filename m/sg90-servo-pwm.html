SG90サーボモーターの制御信号(PWM)

小型サーボモーターSG90は、20msごとに繰り返す信号の「Highの長さ」で角度が決まります。この資料では、その信号の形と、角度からパルス幅を求めるC言語の計算を確かめます。

前提知識

  • PWM(パルス幅変調)は、一定の周期でHigh(5Vや3.3V)とLow(0V)を切り替え、Highの長さで情報を伝える方法です。
  • デューティ比は、1周期のうちHighである時間の割合です。たとえば周期20msでHighが1ms続けば、デューティ比は 1 ÷ 20 = 5% です。
  • SG90の配線は3本で、茶(または黒)がGND、赤が電源(5V)、オレンジ(または黄)が信号線です。

制御信号の図

横軸は時間(ms)。周期は20msのまま変わらず、Highの長さだけが角度に対応します。

角度とパルス幅の対応

角度パルス幅デューティ比
0°0.5 ms2.5%
90°約1.5 ms約7.5%
180°2.4 ms12%

中央のパルス幅は、0°を0.5ms、180°を2.4msとして直線で結ぶと 1.45ms になります。一般的な目安は1.5msです。この差は個体差の範囲に収まるため、実機では動かして調整します。可動範囲の端で「ジー」と唸るときは、最小・最大のパルス幅を少し内側にしてください。

C言語で角度からパルス幅を求める

角度をそのままPWMの設定値にはできないので、まず「0〜180度」を「500〜2400µs」に直線で対応づける関数を作ります。整数の割り算は小数点以下を切り捨てることに注意してください。

#include <stdio.h>

#define PULSE_MIN_US 500   /* 0度のときのパルス幅(マイクロ秒) */
#define PULSE_MAX_US 2400  /* 180度のときのパルス幅(マイクロ秒) */
#define PERIOD_US    20000 /* PWMの周期(20ms = 50Hz) */

/* 角度(0〜180)をパルス幅(マイクロ秒)に変換する */
int angle_to_pulse_us(int angle)
{
    if (angle < 0)   angle = 0;
    if (angle > 180) angle = 180;
    return PULSE_MIN_US + (PULSE_MAX_US - PULSE_MIN_US) * angle / 180;
}

int main(void)
{
    int angle;

    printf("角度  パルス幅[us]  デューティ比[%%]\n");
    for (angle = 0; angle <= 180; angle += 45) {
        int pulse = angle_to_pulse_us(angle);
        double duty = 100.0 * pulse / PERIOD_US;
        printf("%3d   %6d        %5.2f\n", angle, pulse, duty);
    }
    return 0;
}
実行結果(gcc -Wall -Wextra で確認)
角度  パルス幅[us]  デューティ比[%]
  0      500         2.50
 45      975         4.88
 90     1450         7.25
135     1925         9.62
180     2400        12.00

ArduinoのServoライブラリでは、attach(ピン, 500, 2400) のように最小・最大のパルス幅を渡し、write(角度) で角度を指定します。内部では、ここで書いた計算と同じことをしています。

配線のときの注意

  • 電源は外部の5Vを使うのがおすすめです。マイコンの5Vピンから直接取ると、動き出すときの電流でリセットされることがあります。
  • 外部電源を使うときは、マイコンとサーボのGNDをつなぎます。
  • 負荷をかけたまま長時間止めておくと、発熱や故障の原因になります。

よくある間違い

  • 周期まで変えてしまう。変えるのはHighの長さだけで、周期は20msのままにします。
  • デューティ比の単位を取り違える。ms と µs と % を混ぜず、計算の前に単位をそろえます。
  • 0〜180を超える角度をそのまま渡す。上の関数のように範囲内に収めてから計算します。

確認問題

問1 周期20msで、Highが1.0msのとき、デューティ比は何%ですか。

1.0 ÷ 20 = 0.05 なので 5% です。

問2 上のプログラムで、angle_to_pulse_us(60) はいくつを返しますか。

500 + (2400 − 500) × 60 ÷ 180 = 500 + 1900 × 60 ÷ 180 = 500 + 633 = 1133 です。整数の割り算なので、633.33… の小数部分は切り捨てられます。
