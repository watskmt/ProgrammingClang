ポインタ入門

2026-10-14 / 前提: 変数・printf・関数の基本

ポインタは「変数のアドレス(メモリ上の場所)を入れておく変数」です。まず用語を2つだけ覚えます。

書き方意味読み方
&x変数 x のアドレスを求めるアドレス演算子
int *pint 変数のアドレスを入れる変数 p を宣言するポインタ宣言
*pp が指す先の変数そのもの間接参照演算子

1. アドレスと間接参照

p に x のアドレスを入れると、*p を通して x を読み書きできます。

C 
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;

    printf("x の値      : %d\n", x);
    printf("x のアドレス: %p\n", (void *)&x);
    printf("p の値      : %p\n", (void *)p);
    printf("*p の値     : %d\n", *p);

    *p = 100;              // x を書き換える
    printf("x = %d\n", x); // 100
    return 0;
}

実行例(アドレスは実行のたびに変わります)

x の値      : 42
x のアドレス: 0x7ffde8b44650
p の値      : 0x7ffde8b44650
*p の値     : 42
x = 100

x のアドレス と p の値 が同じになる点を確認してください。%p には void * を渡すのが決まりです。

2. 関数で呼び出し元の変数を書き換える

C言語の関数引数は値のコピーです。呼び出し元の変数を変えたいときは、アドレスを渡します。

C 
#include <stdio.h>

void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void) {
    int m = 3, n = 5;
    swap(&m, &n);
    printf("m = %d, n = %d\n", m, n);
    return 0;
}

実行結果

m = 5, n = 3

3. 配列とポインタ

式の中で配列名 a は、先頭要素 &a[0] のアドレスとして扱われます。p + i は「i 要素先」を指し、*(p + i) は a[i] と同じ要素です。

C 
int a[3] = {10, 20, 30};
int *q = a;   // &a[0] と同じ

for (int i = 0; i < 3; i++) {
    printf("a[%d] = %d, *(q + %d) = %d\n", i, a[i], i, *(q + i));
}

実行結果

a[0] = 10, *(q + 0) = 10
a[1] = 20, *(q + 1) = 20
a[2] = 30, *(q + 2) = 30

q + 1 はアドレスが 1 バイト進むのではなく、sizeof(int) バイト進みます。

4. NULL と初期化

どこも指していないポインタには NULL を入れ、使う前に確認します。

C 
int *r = NULL;
if (r != NULL) {
    printf("%d\n", *r);
} else {
    printf("r は NULL です\n");
}
よくある間違い
間違い起きること対策
int *p; *p = 1;未初期化のポインタ経由で書き込み、異常終了や不具合の原因になる宣言時に NULL か有効なアドレスを入れる
関数内のローカル変数のアドレスを return する関数終了後にその領域は無効になる呼び出し側の変数を受け取る、または動的確保を使う
NULL を * で参照する実行時エラー(セグメンテーション違反など)参照前に != NULL を確認する

確認問題

1. int a = 1, b = 2; int *p = &a; *p = b; の後、a の値はいくつですか。
2. 上の swap を、引数を int a, int b(値渡し)にして書き換えると、呼び出し元では何が起きますか。
